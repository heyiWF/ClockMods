## 样式实时预览

设置详情顶部固定显示预览，滚动调整控件时仍可见，并可切换横屏 / 竖屏。复用正式时钟与日历渲染器；模糊强度、卡片亮度、主题配色、字体 / 字重 / 比例、图片背景与压暗等草稿即时反馈。预览模块按需加载，帧内更新合并连续拖动事件。

预览使用隔离视口与只读草稿，不写入偏好、不启动天气请求。已保存图片和待选图片各有独立的临时 URL，关闭时释放，不撤销主页面的背景 URL。取消保持配置与背景不变，应用才保存。

已在 Chrome 验证模糊与亮度拖动、颜色拾取、字体更改、横竖屏切换、临时图片取消、应用保存和日历主题切换；再次通过八种尺寸的设置面板检查。生产包在子路径部署模拟中，预览与 Lora 字体加载通过，无缺失资源或页面错误。

## 日期与辅助文字字号

非经典时钟和五款日历的日期、辅助文字改用 CSS px，共用 8–80 px 范围；经典时钟保留屏宽比例，两项均为 Ultimate 的 20%–200%。控件相邻放在字体分组。旧比例配置只读换算成初始像素值，应用后按主题保存独立像素字号；取消和恢复默认仍按草稿规则处理。

非经典时钟不再对日期额外除以默认比例，日期 / 农历与辅助行使用同一尺寸换算；空间受限时各行按独立区域缩小。经典时钟两项均独立使用相同参考日期宽度计算，辅助文字不再乘在日期字号上。日历单元内的日期和辅助文字分别限制在自身区域。空间足够时，相同字体与字重、相同数值的实际字号一致，实时预览与正式页面共用该规则。

Chrome 验证了非经典时钟的 132 个组合，以及经典主题与 5 款日历在 3 种尺寸、3 档设置下的 54 个组合。实际设置预览中 24 px 日期与辅助文字均测得 24 px；范围、主题切换、取消、应用、旧值读取及重置另有回归测试。

## 平台边界

浏览器验证使用本机 Chrome；未将其表述为全部实体设备或 Safari / Firefox 的实测。方向锁定、安全区与电池由设备 / 浏览器提供。真实 QWeather 凭据联网、实际设备锁屏和后台唤醒未作为本次已通过项；天气解析、请求与失败回退使用自动测试。Web 无 Android 开机自启、桌面小组件和原生闹钟调度，周程尚无 Android 日程编辑。字体栅格化与系统字体由宿主平台决定。

## 本机字体

- 时钟与日历提供完整本机字体款式列表及搜索；浏览器授权后读取，字体文件不上传。固定款式读取 OS/2 字重，可变字体读取 fvar 的 wght 范围，TTC 集合按 PostScript 名称匹配子字体。
- 完整列表需要支持 Local Font Access 的桌面浏览器和安全上下文；未授权、空列表、读取错误及不支持均显示状态，内置字体仍可选。
- Chrome 实机枚举 578 个款式。通过 Chrome 字形来源核对：微软雅黑同时绘制中文和西文；Arial Bold 绘制西文，中文回退默认字体；Bahnschrift 的实际范围为 300–700，437 字重可选择并用于实时预览。

## 日历、多语言与触屏修复

周程独立日历轨道和详情卡、海报横竖布局、选中日期天气与图标对比已对照 Ultimate 修正。简繁英界面、农历、世界城市和应用内时间选择器统一跟随语言。侧栏采用 Google Material SVG。鼠标静止三秒隐藏，打开对话框时保持显示。页面滑动支持速度判断及动画中重新接续，导航不再改变页面高度。

验证：312 项测试、类型检查、生产构建通过；Chrome 30 项日历主题/语言/方向组合、64 项设置布局、20 项最大字号日历、3 项世界城市布局均通过。真实触摸检查连续翻页及动画中接续；鼠标计时、语言切换、城市名和时间单位验证通过。

## 自动字号与区域独立适配

时钟主题和日历默认日期、辅助字号为自动（持久化值 0），根据当前区域的宽高计算；拖动即可改为固定 px，自动按钮可恢复。既有手动值与旧比例迁移保留。日期、天气、标签各自在自身区域缩放，日期与辅助字号不再互相牵动。时间字号先确定可用上限，再应用用户倍率，避免默认即触顶。

石墨/碳黑天气及预报按各自卡片自适应，辅助字号可调整；补齐预报风向、风力和湿度详情。竖屏纵向排列卡片；宜忌前缀加圆形底色、活动用圆点分隔。

验证：317 项单元/集成测试、类型检查和生产构建通过；44 项时钟主题/分辨率组合（含 3840×2160）验证字号独立性与时间缩放，30 项日历组合和 64 项设置布局检查通过。实际 Chrome 截图检查大屏与竖屏天气区。

补充回归：天气关闭时，石墨/碳黑才收起天气区域，纸张/海报/周程继续使用完整页面。10 项天气关闭布局检查通过；自动字号提示在繁体界面互动后仍显示「自動」。

## 月历页脚轮播回环对齐

日期副本在滑入前重新按当前尺寸测量，同时同步原日期行；溢出判断使用整行扣除宜忌前缀后的可用宽度，避免 flex 对齐状态反过来改变测量结果，并容忍 1 px 的整数取整差异。

Chrome 连续两个自然轮播周期验证布局变化后的回环：修复前 22/22 个日期副本入场帧偏移，修复后 0/22；39 项轮播/日历相关测试、类型检查及生产构建通过。

## 日历表头与天气卡片字号

月份标题、星期表头和「今天」按钮统一使用日历辅助文字字号；五款日历均可调整，海报主题同步开放辅助字号控件。

天气和预报按实际内容边界测量后适配字号，计入卡片内边距、详情换行及预报分栏间距；自动字号不再将湿度等末行裁出卡片。预报状态合并到日期标题，例如「今天 晴」「明天 多云」，保留图标、温度范围和风向/风力/湿度详情，腾出的空间用于自动放大内容。

Chrome 使用天气样例验证 7 种分辨率 × 简体中文/英文 × 自动/80 px 共 28 项，检查卡片和分栏边界、标题同行结构及表头字号一致；另通过 64 项设置面板和 20 项日历布局检查。45 项相关回归测试、TypeScript 类型检查和生产构建通过。
