修复后小组件提供跟随主题、系统、衬线、等宽、窄体、细体六个选项，全部使用宿主可加载的系统字体族。旧 Lora 配置迁移为衬线，Bitcount 迁移为等宽，其他旧内置字体迁移为系统字体。App 全屏字体库保持不变。删除小组件专用的重复字体文件及无效布局，预览使用受限上下文，避免再次出现预览与桌面不一致。

## 2026-09-20：前次布局与时区优化

日期：2026-09-20。基于用户提交 `a76e8da`，保留 Material 配置页、字体选择及圆角横向留白。

## 本次改动

- 小组件不显示时区名称、不单独选择时区；数字时钟、指针、日期、农历和午夜刷新统一跟随 App 时区。App 修改时区后自动更新已有实例；空时区设置表示跟随系统。旧 JSON 字段保留兼容读取。
- 固定字体 ID 与资源列的映射，避免字体目录排序改变后选错字体。
- 合并预览滑块的连续请求，跳过过期任务；修复配置页重建时草稿和控件恢复状态的竞争。
- 按宽矮、窄高和大号尺寸调整天气与日期布局，控制主数字高度，确保最大字号下底部文字完整；无缓存天气优先显示可操作的提示。
- 响应式布局共用一次时间与天气快照；去除重复节日名称。
- 修复设备测试将已解析的像素尺寸再次乘密度的问题；新增所有可见文字的实际行高检查，避免仅检查控件边界而遗漏字形裁切。
