Material Symbols Outlined, Rounded, and Sharp variable fonts, version 2.972.

Source: https://fonts.googleapis.com/css2 (Google Fonts CSS API), fetched on
2026-09-24 with `icon_names` limited to the network and battery symbols used by
Ultimate. The returned WOFF2 subsets were converted to TTF without fixing the
variable axes. Codepoints were checked against Google's Material Symbols
Outlined codepoint index:
https://github.com/google/material-design-icons/blob/master/variablefont/MaterialSymbolsOutlined%5BFILL%2CGRAD%2Copsz%2Cwght%5D.codepoints

Each bundled font supports FILL (0–1), GRAD (-50–200), opsz (20–48), and
wght (100–700). These fonts do not include a ROND axis; the shape control uses
the three available Material Symbols families instead.
