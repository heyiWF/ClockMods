# ClockMods Web

**打开浏览器，把一块屏幕变成你的时钟与日程桌面**

十二套时钟主题 · 六个工具页面 · 可安装 PWA · 离线优先 · 无账号

</div>

ClockMods Web 将 Android 版的时钟与常用工具带到现代浏览器：桌面电脑、手机和平板都能使用，不需要先安装 APK。基础界面可静态部署；天气按需直连 QWeather 或连接自己的代理。

[核心亮点](#核心亮点) · [版本选择](#版本选择) · [快速上手](#快速上手) · [开发与构建](#开发与构建) · [许可与致谢](#许可与致谢)

## 核心亮点

- **经典与 Material 风格同在**：经典时钟之外，提供玻璃工坊、黑金仪表、纸感时站、霓虹轨道、数字网格、字形时刻，以及双块、轨道、气泡、混合、丝带十一套独立布局，配合 Material 3 风格设置、导航与交互反馈。
- **一页集合常用时间工具**：时钟、月历、番茄钟、闹钟、倒计时、秒表，可通过导航或左右滑动切换。
- **可安装、离线使用基础功能**：支持 PWA 安装和更新提示；首次成功缓存后，时钟与离线日历等基础页面无需持续联网。天气仍需网络。
- **显示随你的习惯调整**：12 / 24 小时制、隐藏或缩小秒数、竖排大字、字体与比例、本地图片背景、压暗、主题配色、文字对比色与卡片阴影。
- **信息读得清楚，变化看得自然**：七种数字 / 天气过渡，成对数字同步变化、短距离右滑、先出后入的渐变扫描，以及独立天气轮播动效，自定义留言以固定字号横向滚动，温度支持摄氏 / 华氏。
- **日期与天气都在身边**：离线公历、农历、节气、节日与宜忌，实时天气、详细信息与预警；支持简体 / 繁體 / English。

## 主题与工具

### 十二套时钟主题

| 主题 | 视觉特点 |
| --- | --- |
| 经典 | 清晰的大字时间与传统全屏布局 |
| 玻璃工坊 | 金属玻璃表盘与独立信息区 |
| 黑金仪表 | 黑金刻度表盘与秒数仪表 |
| 纸感时站 | 纸张横线、红色边线与模拟表盘 |
| 霓虹轨道 | 时、分、秒三层进度环 |
| 数字网格 | 技术网格与七段数字面板 |
| 字形时刻 | 深浅分区、大字排版与秒数进度条 |
| 双块 | 小时、分钟独立大面板与花瓣秒数徽章 |
| 轨道 | 三层同心轨道、动态秒点与中心时间 |
| 气泡 | 小时矩形、分钟花瓣圆与秒数圆 |
| 混合 | 左右或上下排列的模拟表盘与数字面板 |
| 丝带 | 倾斜底板、胶囊时间条与花瓣秒数徽章 |

时钟和日历分别保存各主题的字体、字重和字号；非经典主题的日期与辅助文字统一使用 8–80 px，经典主题两项均使用 20%–200% 屏宽比例，相同设置值保持实际字号一致，空间不足时同步缩小。时钟还按主题保存配色、自动文字颜色、阴影、卡片模糊与数字 / 天气动效。设置以草稿方式编辑，顶部实时预览支持横竖屏切换，调整模糊、亮度、颜色、字体和背景时立即反馈；应用后保存，取消保留原配置；「恢复当前主题原版配色」可只重置当前主题的三种配色。

字体设置可点击「读取本机字体」，授权后搜索并选择浏览器返回的全部本机字体款式（含各字重、斜体和窄体）。固定字体使用该款式的真实字重，可变字体支持范围内逐级调节；包含中文的字体同时用于中西文，缺失的中文字形回退默认字体。时钟、日历及实时预览共用这一规则。字体文件仅在本机读取，不上传；不支持 Local Font Access 的浏览器继续提供内置字体。完整本机列表需要桌面 Chrome / Edge 等支持该接口的浏览器以及 HTTPS 或 localhost。

数字过渡包括淡变、上滑、下滑、缩放、翻页、右滑、扫描。图片背景可立即或定时压暗；五款 Ultimate 卡片主题支持卡片内高斯模糊，原背景保持清晰，模糊强度和卡片亮度独立调节。可添加并排序最多六座世界时钟城市；整点 / 半点视觉报时提供六种动画和静默时段。Web 的十二套主题按 Ultimate 的独立构图与横竖屏几何实现；桌面小组件仍需 Android 版。字体栅格化和部分材质由浏览器渲染，与 Android 存在平台差异。

### 六个工具页面

| 页面 | 主要用途 |
| --- | --- |
| 时钟 | 全屏时间、日期、天气、留言与整点视觉报时 |
| 月历 | 月份切换、日期点选、回到今天、农历、节气、节日、宜忌与休 / 班标记 |
| 番茄钟 | 工作、短休息与长休息阶段循环 |
| 闹钟 | 设置提醒时刻与重复规则，按浏览器能力播放声音、振动或通知 |
| 倒计时 | 自定义时长与快捷预设，保存结束时间以便刷新后继续计算 |
| 秒表 | 连续计时与分段计次 |

日历使用 [tyme4ts](https://github.com/6tail/tyme4ts) 在本地计算，法定节假日安排来自打包的 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 数据，仅覆盖已收录年份。Web 提供石墨、纯黑、纸历、海报、周程五种日历布局；周程可按周浏览日期，但不包含 Android 本地日程数据库与编辑功能。

设置采用八类导航：宽屏左右分栏，窄屏分类首页与详情页。方向锁定、电池状态等能力依赖浏览器，显示保护支持定时位移与压暗。实现与验收范围见 [Web 设置验收记录](docs/WEB_SETTINGS_ACCEPTANCE.md)。

## 快速上手

1. 打开已部署的站点，或在本地运行下文开发 / 预览命令。
2. 双击时钟或点击设置按钮，选择主题、背景、字体和显示信息，点击「应用」保存。取消不会覆盖已有配置。
3. 使用导航切换工具页；需要天气时按下文配置直连凭据或代理。
4. 支持安装的浏览器可将站点添加到桌面。PWA、定位和屏幕常亮等能力通常要求 HTTPS 或 localhost，并取决于浏览器支持。

### 浏览器能力与使用边界

| 能力 | 实际条件 |
| --- | --- |
| 离线页面 | 首次加载并完成 service worker 缓存；清除站点数据会移除缓存与本地设置 |
| 屏幕常亮 | 依赖 Screen Wake Lock，通常需安全上下文且页面可见；不支持时请在设备设置中调整自动锁屏 |
| 全屏与方向锁定 | 取决于浏览器、设备、用户操作与全屏 / 安装状态，不能在所有平台强制锁定 |
| 闹钟、倒计时与报时 | 页面应保持运行；后台节流、休眠或关闭页面可能延迟或停止提醒，声音与通知还受权限限制 |
| 网络校时 | 使用 HTTP HEAD 的 `Date` 响应头，并非原生 UDP NTP；精度受时间戳粒度与网络影响 |

安装 PWA 不会自动获得 Android 原生闹钟调度或桌面小组件能力。纯色、日期、农历与基础计时不需要天气服务。

## 天气与校时配置

### QWeather 直连或代理

直连模式在设置中填写 API Host、凭据 ID、项目 ID 与 PKCS#8 Ed25519 私钥 Base64，浏览器生成 JWT 请求天气。自动定位需要浏览器位置权限，也可手动选城市。天气支持缓存、更新间隔、详细轮播与摄氏 / 华氏切换。

也可配置自己的代理 URL，将签名留在服务端。仓库提供 [Cloudflare Worker 示例](proxy/cloudflare-worker.js)，部署前按文件说明填写环境变量与允许的来源；其他平台需要适配各自请求入口。代理负责跨域响应与天气接口转换，页面本身仍是静态站点。

### HTTP 校时

填写允许 HEAD 请求且返回 `Date` 头的 HTTP / HTTPS 地址。跨域地址还需允许站点来源，并通过 `Access-Control-Expose-Headers: Date` 公开该响应头；HTTPS 页面应使用 HTTPS 校时服务。失败时基础时钟继续使用本地时间或已有有效偏移。

## 本地数据与隐私

无需账号，不含广告或用户行为统计。设置与直连凭据保存在当前浏览器的 `localStorage`，选取的背景图片保存在 IndexedDB；没有内置云同步。使用不同浏览器或清除站点数据后，需要重新设置。

联网只用于已启用的天气、校时，以及站点资源加载 / PWA 更新。天气会向 QWeather 或所选代理发送城市或定位坐标；直连模式上传签名令牌，私钥保存在本地配置中。代理的数据处理由所选服务决定。

## 开发与构建

开发环境推荐 Node.js 22.12+ 与 npm，使用仓库锁文件安装依赖：

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

生产文件输出到 `dist/`，可部署到静态站点服务。天气代理是可选的独立服务，不属于静态页面部署的必需组件。

### 源码与贡献

```text
src/              TypeScript 页面、设置、时间与天气逻辑
src/styles/       Material 令牌、交互样式与主题布局
public/           图标、静态资源与许可文件
proxy/            可选天气代理示例
tests/            核心逻辑、DOM 与主题测试
```

Material 风格由共享颜色、字阶、形状和动效令牌构成，界面同时保留键盘聚焦与状态反馈。构建使用 Vite 与 TypeScript，PWA 缓存由构建插件生成。

反馈问题时请附浏览器 / 系统版本、主题、窗口尺寸及复现步骤。提交变更应运行类型检查、测试和生产构建；布局与动效需检查窄屏和横屏，离线与安装体验需用生产预览验证。
